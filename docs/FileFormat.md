# シンボル・属性ファイル（Import / Export）フォーマット仕様書

## 1. 概要
本仕様書は、逆アセンブラおよび内部ハンドラ（`CLabelHandler`, `CAttrHandler`）間において、**シンボル情報（ラベル、EQU、エイリアス、コメント）**および**メモリ領域のデータ属性（コード/データ種別）**を相互運用するためのテキストファイルフォーマットを定義する。

---

## 2. 基本フォーマット

本ファイルはプレーンテキスト形式（文字コード: UTF-8 / Shift-JIS / ANSI 対応）で記述する。改行コードは `CRLF` または `LF` とする。

### 1行の基本構造
```text
[識別子/アドレス] <タブ/スペース> [パラメータ/シンボル名] <タブ/スペース> [; コメント]
```

* **区切り文字**: 空白文字（半角スペースまたはタブ）
* **コメント**: 半角セミコロン `;` 以降（改行まで）をコメントとして扱う。

---

## 3. 記述ルール・指定子一覧

| 種別 / 識別子 | パラメータ | 説明 |
| :--- | :--- | :--- |
| **アドレス** (`$XXXX`) | `シンボル名` | 指定アドレスに通常ラベルを定義。 |
| **`EQU`** | `$値` `シンボル名` | 定数・I/Oレジスタ名を定義（アドレス置換用）。 |
| **`DB`** | `$アドレス` [`- $終了アドレス`] | 該当範囲を **1バイトデータ（Data Byte / FCB）** として定義。 |
| **`DW`** | `$アドレス` [`- $終了アドレス`] | 該当範囲を **2バイトワード / ポインタ（Data Word / FDB）** として定義。 |
| **`DC`** | `$アドレス` [`- $終了アドレス`] | 該当範囲を **文字列データ（Data Character / FCC）** として定義。 |
| **`CODE`** | `$アドレス` [`- $終了アドレス`] | 該当範囲を **実行可能コード領域** として定義（データ指定を解除）。 |

---

## 4. 記述例

### ① データ属性の指定 (DB / DW / DC)
命令解析（コード）ではなく、データとして逆アセンブル出力させたいメモリ領域を指定する。単一アドレス指定および範囲指定に対応する。

```text
DB       $1000           ; 1バイトデータ（16進数出力）
DW       $1020           ; 2バイトワード / アドレスポインタ
DC       $1050           ; 文字列データ（ASCII表示）

; 範囲指定の例
DB       $2000-$200F     ; $2000〜$200F を1バイトデータ群に設定
```

### ② 通常ラベル (Label)
指定アドレスにラベルを定義する。データ属性が指定されたアドレスと併用することも可能。

```text
$C000    MAIN_LOOP       ; メイン処理の開始ルーチン
$1020    PTR_TABLE       ; ワードデータ（DW）位置のラベル
```

### ③ 定数・I/Oレジスタ定義 (EQU)
定数として定義し、直接値の参照箇所を名前で置換表示する。

```text
EQU      $0000   PORT1   ; Port 1 Data Register
EQU      $0008   TCSR    ; Timer Control and Status Register
```

### ④ エイリアス (別名定義)
同一アドレスに対して複数のラベル行を記述した場合、自動的に**エイリアス（別名リスト）**として追加登録される。先頭の記述がプライマリ（代表名）となる。

```text
$FFF0    VEC_SCI         ; Serial Communications Interface Interrupt
$FFF0    INT_SCI_SER     ; (Alias) シリアル割込別名
```

---

## 5. インポート・エクスポート時の動作仕様

### インポート時 (Import)
1. 空行および `;` から始まるコメント行は無視する。
2. 行頭の識別子（`DB`, `DW`, `DC`, `CODE`, `EQU`, `$アドレス`）に基づいて処理を分岐する。
3. **データ属性（DB/DW/DC）** の指定がある場合、`m_pAttrHandler` を呼び出して該当アドレスの属性フラグを設定する。
4. **ラベル / EQU** の指定がある場合、`m_pLabelHandler` へ登録する。同一アドレスへの複数登録は `pAliasList` へ追加される。
5. 行末にコメントが存在する場合は、該当ノードの `tszComment` に格納する。

### エクスポート時 (Export)
1. **[第1セクション: EQU定義]**
   * 登録されている全EQUシンボルを `EQU  $XXXX  シンボル名` 形式で先頭に出力する。
2. **[第2セクション: データ属性定義]**
   * `m_pAttrHandler` に登録されているデータ領域（DB/DW/DC）をアドレス順に出力する。
3. **[第3セクション: ラベル・コメント定義]**
   * 各アドレスのラベル、エイリアス、および関連コメントを出力する。
